# Phoenix Pro Windows release notes

## Release

- Version: `0.1.0-preview`
- Installer: `Phoenix-Pro-Setup.exe`
- Optional package: `Phoenix-Pro.msi`
- Integrity: accompanying `.sha256` files

## Included

- Tauri 2 desktop shell.
- Phoenix workstation UI.
- Safe native runtime boundary.
- Installer, uninstall, Start Menu, WebView2 bootstrapper, and checksum automation.

## Not included

- Real USB/ADB/Fastboot servicing.
- Destructive erasure or firmware flashing.
- Password recovery, FRP bypass, Activation Lock bypass, or credential extraction.
- Production customer records, SQLite persistence, or verified certificates.
