# Contributing

Keep device operations behind narrow, typed command boundaries. Do not add a UI action that implies an underlying operation is available unless the adapter, compatibility evidence, verification path, and physical-device tests exist.

Use strict TypeScript, preserve provenance labels, keep sample data visibly marked, and update `plan.md`, `TODO.md`, `README.md`, and `CHANGELOG.md` when scope changes. Run `pnpm build` before handoff.
